Wuxing Animation Manager — Guide

1. Auto-Loading Files in tools/animation_manager/:
• With local server (http://localhost): Automatically fetches character.glb, humanoid_anims.glb, and all *.fbx/*.glb files in the directory on startup.
• Without server (file://): Browsers block silent file:// directory reads, so click Open Folder once (or drag-and-drop all files onto the window) — it automatically routes character.glb → Character, humanoid_anims.glb → Anim Bank, and all other .fbx/.glb → Raw Animations.

2. Where Name & Description are stored:
• Inside humanoid_anims.glb: animations[i].name (keep <= 31 chars for Raylib) and animations[i].extras (description, slot, loop, tags, ai_usage).
• Sidecar player_anims.json: Export alongside .glb so both character_model.c and AI coding agents can read every clip's description directly.
